# 功能覆盖表

状态含义：**已实现**表示源码和定向测试有证据；**部分**表示有实现但本轮未完成真实环境闭环；**未验证**表示需要真实 Host、平台账号或独立 QQ 发送端；**不实施**表示按任务书明确延后。

| 编号 | 能力 | 状态 | 证据/边界 |
|---:|---|---|---|
| 1 | Life 状态、活动、意图与概况可见 | 已实现 | 新增 `lifeSummary` 和设置页概况卡；219/219 测试通过 |
| 2 | Life 与 State/Experience 联动 | 已实现 | 派生读取覆盖三者；无额外存储 |
| 3 | 连续人格、Memory、State、Experience | 已实现/部分 | Core 原有接口保留；跨真实平台回忆需现场验收 |
| 4 | B 站读取 | 部分 | 既有适配器和测试保留；本轮未重复访问外部平台 |
| 5 | 小红书读取 | 部分 | 既有适配器和证据链保留；旧评论精确回读仍独立延后 |
| 6 | 跨对话经历回忆 | 部分 | Experience owner/ACL 读取保留；需真实 Host 另开授权 Session 验收 |
| 7 | 原生记忆图谱与来源定位 | 已实现/部分 | 既有图谱和 ACL 代码保留；本轮未使用 GUI 重跑 |
| 8 | 普通 DSH 对话 | 未验证 | 本轮只做源码、构建和 Node 测试 |
| 9 | QQ 出站 | 未验证 | QQ 仓库未修改；需要运行中的 NapCat 和授权发送证据 |
| 10 | QQ 自然入站全链路 | 未验证 | 不能用 Bot 自发或人工 Host 投递冒充；需独立 QQ 发送端 |
| 11 | 断线重连、Session 复用、去重 | 已实现/部分 | Core/QQ 既有实现保留；本轮未做生产 NapCat 回归 |
| 12 | 自然唤醒自主探索闭环 | 未验证 | 未制造任务；需自然唤醒→真实平台→Experience→回忆证据 |
| 13 | 主动联系机制 | 部分 | Life 有受控外部消息 Session 绑定；不自动扩大收件人或发送权限 |
| 14 | 资源预算与休息 | 已实现/部分 | 原有活动预算和状态保留；本轮未做长时间自然运行 |
| 15 | Mneme/Memory 兼容 | 已实现 | 本轮未改内部 schema/算法，使用现有接口 |
| 16 | 运行态可回读、重启保持 | 部分 | 代码和持久化路径保留；本轮未重启主环境 |
| 17 | 新通用链接解析器接入 | 不实施 | 本轮任务范围集中于 Core 最终整合；不引入新平台或重复解析系统 |

编号 10 的“按用户要求不实施”旧项在本轮改为“未验证”，原因是代码路径保留但真实入站证据仍缺独立发送端；没有把它宣称为完成。
