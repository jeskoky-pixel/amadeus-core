# Amadeus 真实平台适配器测试计划（仅计划，未实施）

状态：未来工作草案。当前仓库**没有真实 Bilibili/小红书适配器、真实登录、真实网络读取或真实社交动作**。本文不声称任何真实平台测试已经运行，也不把模拟通过当作真实平台准入。
本文适用于未来真实适配器通过许可证与安全评审后的验证；当前可执行范围仍是 `simulation-bilibili` 与 `simulation-xiaohongshu`。

## 1. 目标与不变量

真实适配器上线前必须同时满足：

1. **身份可信**：账号与凭据由可信 Host 注入，模型、普通 HTTP 和平台 fixture 不能注册适配器或自报账号。
2. **只读默认**：首次接入只允许明确列出的读取能力；评论、点赞、关注、私信、发布默认关闭。
3. **逐操作授权**：每个平台、每个操作、每个 Session/场景分别授权；权限不继承 MCP，也不从模拟授权自动升级。
4. **预算与撤销**：每次调用有预算、超时、并发限制和撤权检查；失败与未知回执不自动重试。
5. **证据分级**：`simulation`、`dry-run`、`live-read`、`live-write` 必须可区分；最终等级命名由契约评审确认，但不得复用 `simulation` 表示真实动作。
6. **用户数据分离**：测试只使用隔离合成账号或专用测试账号，不触碰生产账号、生产 Profile、真实社交对象或真实用户数据。
7. **可删除**：撤销令牌、清除账号、卸载适配器后，不再有后台任务、定时器、缓存或出站队列。

## 3. 准入前置条件

在写第一行真实请求代码前：

- 完成平台许可证、服务条款、robots/API 政策与内容合规评审。
- 确认允许的认证方式与域名；禁止自定义登录 URL 和未审核代理。
- 设计凭据模型：令牌只进入 Host 私有存储，界面只显示掩码与引用；不写日志、不进模型上下文、不进公共配置。
- 定义真实证据等级、字段和“未知回执”语义。
- 定义网络出口白名单、重定向策略、超时、限速、重试禁止规则。
- 准备隔离测试账号、测试 Workspace、合成测试数据与清理脚本。
- 明确回滚：删除账号、撤销授权、回滚适配器版本、恢复模拟状态。

## 4. 分阶段测试计划

### P0：契约与威胁建模（无网络）

**目的：** 在接触真实平台前冻结接口与失败语义。

测试项：

- 适配器形状：ID、`contractVersion`、能力清单、`execute`、取消信号。
- 真实适配器不得声明 `simulated: true`；注册路径不得来自 HTTP/模型。
- 输入上限：ID/target/query/text 长度、limit 范围、未知字段拒绝。
- 输出上限：序列化 ≤ 64 KiB；不可 JSON 序列化即拒绝。
- 可信信封：`eventId`、`platform`、`accountId`、Workspace/Session/Activity 由 Core 重建，适配器伪造无效。
- 错误码：未授权、预算耗尽、超时、取消、撤权、未知回执、结果超限。
- 威胁建模：令牌泄露、SSRF、重定向、DNS 重绑定、日志注入、提示注入、跨账号串读。

**退出条件：** 契约评审通过；安全评审记录风险与接受人；没有未决的高危问题。

### P1：适配器单元与本地假服务

**目的：** 不连接真实平台，验证协议解析和失败分支。

测试项：

- 本地假服务返回成功、空结果、畸形 JSON、超大响应、慢响应、429/5xx、重定向。
- 超时与取消：迟到结果不写经历、不重试、不产生第二次副作用。
- 限流：并发与时间窗；预算先扣后发，失败不退款。
- 凭据：请求头只出现一次；日志、错误、事件、概览均不含令牌。
- 重定向：跨域重定向不携带 Authorization；拒绝或按白名单处理。
- 证书/代理：仅使用配置允许的出口；不接受任意用户 URL。

**退出条件：** 全部确定性测试通过；无真实网络；失败路径有可读证据。

### P2：隔离测试账号登录（真实网络，仅测试账号）

**目的：** 验证真实认证与凭据生命周期，不做任何社交动作。

前置：专用测试账号、隔离 Workspace、用户明确同意、平台条款允许自动化。

测试项：

- 启动登录前后 UI 状态准确：未登录、等待授权、已登录、过期、撤销、失败。
- OAuth/扫码只在官方域完成；Core 不接收密码。
- 令牌只保存于 Host 私有存储；重启后可恢复；删除后不可恢复。
- 账号身份展示：昵称、平台 ID、授权范围、过期时间；不显示令牌。
- 多账号隔离：账号 A 的读取不能使用账号 B 的凭据；切换账号清空会话级缓存。
- 撤销：平台侧撤销、Core 侧删除、适配器停止三条路径均生效。
- 失败关闭：令牌无效、网络失败、平台风控时拒绝读取，不降级为模拟结果。

**退出条件：** 登录与撤销全链路通过；无社交动作；证据明确标注测试账号与隔离环境。

### P3：真实只读金丝雀

**目的：** 用最小读取验证真实内容解析与证据分级。

测试项：

- 只读少量公开内容：`browse`/`read`/`search`（按平台实际能力裁剪）。
- 内容字段映射：ID、标题、作者、时间、标签、评论/图片描述等；缺失字段按空集合而非伪造。
- 编码、分页、限流、空结果、内容删除、账号无权限。
- 中文与英文查询分别验证；区分“无结果”和“调用失败”。
- 证据等级为 `live-read`（或评审确认的名称），不是 `simulation`。
- 结果不进入模型上下文之外的未授权存储；Memory 写入仍受 Session ACL。
- 不对图片/视频声称做过未执行的视觉分析。

**退出条件：** 只读成功与失败路径均可解释；无写操作；证据可复核。

### P4：真实社交动作最小化验证（默认不做）

**目的：** 仅当产品明确需要且平台条款允许时，验证一个最小、可撤销的动作。

要求：

- 使用专用测试账号和专用测试对象；不得对真实用户、生产内容或公共账号执行。
- 默认关闭；每次执行前二次确认，显示目标、内容、不可逆性和预算。
- 先生成预览/dry-run；真实动作只在用户明确确认后执行一次。
- 未知回执必须标记未知，禁止自动重试；提供人工核对与停止入口。
- 记录请求 ID、时间、目标、结果和证据等级；不记录令牌。
- 验证撤销授权后动作被拒绝；验证平台限流/风控下失败关闭。

**退出条件：** 动作可撤销、可审计、无重复副作用；否则不进入产品。

### P5：故障、恢复与并发

测试项：

- 网络断开、DNS 失败、超时、平台 5xx、429、响应截断。
- 进程崩溃后重启：不自动重放未知动作；只读可安全重试时也必须显式。
- 同一账号并发读取、不同账号并发、预算竞争、撤权竞争。
- 时钟回拨、预算跨天、重启后额度恢复。
- 适配器版本升级/回滚：旧数据仍可读；失败时回滚到模拟状态。
- 卸载：停止定时器/队列，删除凭据，不留后台进程。

**退出条件：** 无重复副作用；未知状态可见；回滚演练通过。

### P6：隐私、安全与合规复核

测试项：

- 日志、事件、错误、截图、备份中无令牌、Cookie、密码、私有内容。
- 提示注入：平台标题/评论中的“忽略管理员权限”只作为不可信数据。
- 跨 Session/Workspace 读取拒绝；Owner 与非 Owner 边界。
- 数据保留、删除、导出、撤回同意。
- 依赖漏洞扫描与许可证清单；锁文件与供应链检查。
- 平台条款、速率限制和自动化政策复核。

**退出条件：** 安全评审签字；无高危未决问题；合规结论有记录。

### P7：发布前验收与证据冻结

测试项：

- 在隔离 Profile 上完成一次端到端：登录 → 只读 → 经历 → State → 重启 → 撤权 → 删除。
- 用同一脚本重复运行，结果确定；证据文件带时间、版本、环境、账号类型（合成/测试）。
- 明确区分：单元通过、本地真实协议通过、真实只读通过、真实写入通过。
- 不使用“已支持真实平台”描述尚未通过的步骤。
- 冻结测试结果与源码版本；不把历史夹具结果当作当前发布通过。

**退出条件：** 发布清单逐项有证据；任何未验证项保持“未验证”。

| 层级 | 网络 | 账号 | 允许动作 | 证据标签 |

## 6. 未来登录界面：建议步骤（当前不存在这些按钮）

当前 `platform-panel.js` 只有模拟平台启用、权限、每日上限和受控模拟调用；**没有真实登录、二维码、账号绑定、OAuth 或凭据管理按钮**。以下仅为未来建议，不得写成现有功能：

1. **入口分离**：在“真实账号（未实现）”区域提供登录入口，与模拟平台明确分开；默认折叠并标注风险。
2. **选择方式**：展示平台官方支持的认证方式（如扫码或 OAuth）；不提供自定义登录 URL 或密码输入。
3. **官方域确认**：显示将打开的域名、用途、隐私说明和取消按钮；域名来自可信配置，不能由模型或 URL 参数决定。
4. **外部完成授权**：用户在官方页面扫码/登录/同意；Core 不读取密码，不代理登录页面。
5. **回调与校验**：只接受已登记的本地回调和 state/nonce；拒绝未知来源、重放和跨账号回调。
6. **保存引用**：令牌进入 Host 私有存储，界面只显示掩码/引用 ID、创建时间、过期时间；不提供“查看明文”。
7. **展示账号与范围**：显示昵称、平台 ID、授权能力、测试/真实标识、最后验证时间。
8. **逐项授权**：读取能力默认最小集合；社会动作默认关闭，每项单独确认，并显示“可能产生真实外部影响”。
9. **撤销与删除**：提供撤销令牌、删除账号、停止适配器；操作后重新读取状态，验证后台任务已停止。
10. **证据提示**：真实结果带 `live-*` 标签；模拟结果永远显示 simulation；未知回执显示“状态未知，请人工核对”，不显示成功。
11. **故障状态**：登录失败、令牌过期、平台风控、网络失败分别显示可操作错误；不自动重试写操作。
12. **审计入口**：显示最近调用元数据（时间、操作、结果等级），不显示令牌或完整私有内容。

## 7. 证据与报告格式

每个阶段至少记录：

- 日期、Core 版本、适配器版本、Node/DSH 版本；
- 环境：隔离 Profile、Workspace、合成/测试账号标识（不写真实凭据）；
- 测试命令或脚本路径；
- 通过/失败/跳过数量；
- 失败原因与是否阻塞；
- 证据等级：`simulation`、`dry-run`、`live-auth`、`live-read`、`live-write`；
- 明确“未验证”项。

禁止：

- 用模拟结果补真实证据；
- 用历史日志冒充当前版本通过；
- 把“连接成功”写成“授权成功”；
- 把“接口返回 200”写成“内容已正确解析”；
- 把一次测试账号运行写成“生产可用”。

## 8. 验收门槛

真实平台适配器进入产品前，至少满足：

1. P0–P3、P5–P7 通过；P4 仅在明确产品需求下执行。
2. 无高危安全、隐私、许可证或条款问题。
3. 凭据生命周期、撤销、删除、卸载全部可验证。
4. 未知回执不会自动重试或伪造成完成。
5. 真实证据等级与模拟证据在 UI、事件、Memory 中可区分。
6. 失败关闭：认证、网络、权限、限流任一失败时不返回模拟或缓存数据冒充真实结果。
7. 有回滚到模拟适配器的演练记录。

## 9. 明确不做

- 不在本文所述计划外提前接真实平台。
- 不使用生产账号、生产 Profile、真实用户内容或真实社交对象做测试。
- 不通过模型、普通 HTTP 或平台 fixture 注册真实适配器。
- 不自动执行评论、点赞、关注、私信、发布。
- 不把 MCP 权限、模拟平台权限或 State 效果当作平台授权。
- 不因本计划存在就宣称真实登录或社交能力已实现。
