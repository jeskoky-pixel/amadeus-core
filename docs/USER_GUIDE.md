# Amadeus Core 当前使用说明

## 打开

1. 启动已安装的 DSH Host。
2. 打开 Amadeus Core 原生控制台，选择当前工作区并应用配置。
3. 在“总览”确认 Core、Memory、Life、State、Persona 已挂载；在“人格”“记忆”“状态”“经历”查看对应内容。
4. 打开“生活”页查看 Life 的活动、意图和当前生活概况。概况卡展示下一次复查、当前活动、最近经历和兴趣；它是只读汇总，不会替你创建任务。

## 第一次对话

在 DSH 普通对话中直接发送：

> 你最近有什么真实经历？请只说你能从当前记忆和经历记录确认的内容。

这条消息可以确认人格、记忆和经历是否连通，也能避免把没有发生过的平台活动当成事实。

## QQ

QQ 仍由独立 QQ 插件和 NapCat 负责发送。Life 的外部消息 Session 绑定只是提示层的显式授权，不会自动扩大收件人或绕过 QQ 权限。真实入站需要一个独立 QQ 账号向已授权私聊或群聊发送消息；Bot 自己发给自己不算入站验收。

## Life

Life 可以选择行动、整理、休息或保持沉默。不要为了证明自主性人为增加任务。真实平台经历只有在工具成功读取并由 Experience 保存后，才应在后续对话中被描述为已发生。

## 暂停与恢复

需要停止活动时，在 Life 设置中使用现有暂停/恢复入口；修改 State 或 Life 配置后按界面提示应用。若平台需要扫码、验证码或新的权限，先停止该项，不要把失败写成经历。
