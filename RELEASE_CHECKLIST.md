# Candidate/release checklist

- [ ] Four module behavioral regressions pass; archive/replace upstream-only packaging checks explicitly.
- [ ] One Bundle, one client loader, complete Host/UI/assets, license attribution.
- [ ] Workspace, ordinary Session, QQ Scene, fork/subagent and revocation boundaries verified.
- [ ] Original data migration, failed migration, restart and rollback exercised with real-format synthetic stores.
- [ ] Persistent activity Session, two simulated platforms, bounded work, no replay, authorized experience reads.
- [ ] Owner-only UI writes, save/discard/conflict, light/dark, first installation and module disable.
- [ ] QQ remains optional; no NapCat fallback or duplicate scheduler.
- [ ] Package content scan, SHA-256 and installed artifact verification.
- [ ] All limitations recorded; no simulated result described as real platform access.
- [ ] User explicitly authorizes release. This task does not authorize publishing Core.

Do not clear an unchecked item merely because a neighboring test passed.
